# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `0.1.0-beta.x` | Yes |
| Older or unofficial builds | No |

## Reporting a vulnerability

Do not open a public issue. Use GitHub's **Report a vulnerability** form in the repository Security tab: `https://github.com/vibeeeng/YaverVoice/security/advisories/new`.

Include the affected version or commit, platform, impact, reproduction steps, and a minimal proof of concept. Remove API keys, personal audio, transcripts, and other private data.

You should receive an acknowledgement within seven days. Maintainers will coordinate validation, remediation, disclosure timing, and credit through the private advisory. Please do not publicly disclose the issue until a fix or coordinated disclosure is ready.
